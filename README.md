## 🤔 为什么做这个库？

大部分开源项目的代码不错，但 README 写得像密码本——没有图、没有示例、没有结构，用户 3 秒就关掉了。

**README 是开源项目最大的转化率杠杆。** 这个库给你：

1. 📄 **4 套实战模板** —— 覆盖最常见的项目类型，复制改字即用
2. 🏷️ **徽章大全** —— 常用徽章代码 + 使用建议
3. 📖 **写作指南** —— 让人 30 秒决定点 Star 的十条军规

## 📄 模板一览

| 模板 | 适用 | 特色 |
| --- | --- | --- |
| [开源库模板](templates/library.md) | npm/PyPI 等代码库 | 特性列表、API 表格、竞品对比表、路线图 |
| [应用工具模板](templates/application.md) | 有界面的应用/网站 | 截图位、多种安装方式、FAQ 折叠块、贡献者头像墙 |
| [CLI 工具模板](templates/cli.md) | 命令行工具 | 选项表格、配置文件说明、asciinema 演示位 |
| [Awesome 合集模板](templates/awesome.md) | 资源合集 | 符合官方 awesome 规范，可申请收录进 awesome 主列表 |

## 🏷️ 徽章大全

[badges.md](badges.md) 收录了 GitHub 数据徽章、包管理徽章、CI 徽章、自定义文字徽章，以及贡献者头像墙和 Star 增长曲线的用法。

## 📖 写作指南

[guide.md](guide.md)：README 黄金结构、十条军规、提升曝光的仓库设置、发布前自查清单。

## 🚀 快速开始

1. 从 [templates/](templates/) 挑一个最接近你项目的模板
2. 复制内容，替换所有 `【占位符】`
3. 删掉用不到的章节（模板是「全集」，你的 README 应该只留需要的）
4. 用 [guide.md](guide.md) 的自查清单过一遍
